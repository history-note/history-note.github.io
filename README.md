# 📜 한국사 공부 노트

인물과 사건 **100카드**로 배우는 한국사 학습 웹앱입니다.
초등 저학년 자녀와 부모가 함께 보거나, 한국사능력검정시험 기초를 훑을 때 쓰도록 만들었습니다.

- 주소: **https://history-note.github.io/**
- 파일 하나(`index.html`)로 동작합니다. 설치·로그인·인터넷 연결 없이 폰·태블릿 브라우저에서 열립니다.

## 수록 내용 — 8대 시대 · 100카드

| 시대 | 카드 | 범위 |
|---|---|---|
| ① 고조선·삼국시대 | 13 | 기원전 2333 ~ 676 |
| ② 남북국시대(통일신라·발해) | 12 | 676 ~ 926 |
| ③ 고려 | 12 | 918 ~ 1392 |
| ④ 조선 전기 | 12 | 1392 ~ 1592 |
| ⑤ 조선 후기 | 13 | 1592 ~ 1876 |
| ⑥ 개항기·대한제국 | 12 | 1876 ~ 1910 |
| ⑦ 일제강점기 | 13 | 1910 ~ 1945 |
| ⑧ 대한민국 현대 | 13 | 1945 ~ 오늘 |

카드 앞면에는 시대 배지·이름·"시험에 이렇게 나와요" 질문이, 뒷면에는 연도·생몰,
왜 중요한지(2~3문장), 핵심 키워드가 들어 있습니다.

## 기능

1. **📖 카드 학습** — 시대 필터 8개, 탭이나 좌우 스와이프로 넘기기, 종이 넘김 효과음,
   진행률 표시, 카드 섞기.
2. **🎯 퀴즈** — 시대별 또는 전체에서 10문제 4지선다. 정답·오답 효과음, 바로 나오는 해설,
   결과 점수와 틀린 문제 목록, "틀린 문제만 다시 풀기".
3. **⏳ 한눈에 연표** — 시대순 전체 목록, 인물·사건·키워드·연도 검색, 시대 점프,
   항목을 누르면 그 카드로 이동.
4. **📌 오답노트** — "헷갈려요"를 누르거나 퀴즈에서 틀린 카드가 자동 저장되고,
   "이제 알아요"로 해제할 수 있습니다. 헷갈린 카드만 모아 퀴즈도 풀 수 있습니다.

## 개인정보

- 모든 학습 기록은 사용하는 브라우저의 `localStorage`에만 저장됩니다. 서버로 보내지 않습니다.
- 외부 스크립트·폰트·이미지·분석 도구를 쓰지 않습니다. 요청은 이 페이지 하나뿐입니다.
- 회원가입, 광고, 추적이 없습니다.

## 사실 확인

- 연도·인물·업적은 교과서·한국민족문화대백과·국사편찬위원회 사료를 기준으로 작성했습니다.
- 전설이거나 기록이 갈리는 항목은 카드에 그렇게 표시했습니다
  (예: 단군왕검 `기원전 2333년(전설)`, 고조선 8조법 `기원전 2세기경 기록`).
